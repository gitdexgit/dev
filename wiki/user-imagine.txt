THE IDENTITY
  dex     = The lab. Tinker, break things, push limits.
  imagine = The operator. Pure vanilla defaults. Get to work.

------------------------------------------------------------------------
THE RULES
  1. Empty Pockets:
     ~/.local/bin is empty. No custom scripts. No wrapper aliases.

  2. The Runbook Rule:
     Bring notes, but read-only. Read the command, understand the flags,
     type it manually. Notes teach; scripts make you lazy.

  3. Non-Destructive dex:
     In dex, never break standard grammar (y, d, p, :w, POSIX basics).
     If imagine can't use it, dex shouldn't bind it.

  4. Stock Tools Only:
     Default bash. Stock vi/vim. :Ex for files, :ls/:b for buffers.

------------------------------------------------------------------------
THE 7 TIERS (When dropped on an unknown machine)
  1. Full access     -> git clone wiki and read.
  2. Restricted net  -> Plug in USB/phone, grep notes locally.
  3. Locked down     -> Browser -> search notes on GitHub.
  4. Air-gapped      -> Phone in pocket (Termux/NetHunter) -> read offline.
  5. Blocked phone   -> Switch to secondary laptop/device.
  6. Zero tools      -> Trust muscle memory. You typed it enough times.
  7. Total blank     -> Drop ego. Read man pages, ask someone, get it done.
