# slow is smooth, smooth is fast

CORE PRINCIPLE
  Consistency beats speed. Universality beats customization.
  If it doesn't work on a fresh, bare-metal install, don't rely on it.

THE TRAP
  - Spending hours tuning bespoke aliases and plugin-heavy configs.
  - Memorizing 10 editor-specific tricks instead of 1 shell tool.
  - Becoming helpless the moment you SSH into a remote or foreign machine.

THE RULES
  1. Default is king
     Stick to vanilla tools and standard flags. Your muscle memory
     should work on any Linux box, server, container, or rescue shell.

  2. Separate concerns
     Vim edits text. The shell manages files.
     Use the shell (Ctrl+Z / fg) for shell work; don't force your
     editor to do everything.

  3. Eliminate hesitation
     Saving two keystrokes with a niche command is a loss if you pause
     to remember it. One consistent habit applied everywhere is faster
     in the long run.

THE GOAL
  Sit down at any terminal on Earth, open zero config files,
  and get straight to work without friction.
